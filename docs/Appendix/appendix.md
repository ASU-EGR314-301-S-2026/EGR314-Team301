## Thumbnails for large files

Large images and PDFs are shown as thumbnails for faster page load. If a thumbnail is missing, add a smaller PNG alongside the original file using the same name with `_thumb` suffix, for example `diagram.png` and `diagram_thumb.png`. The page will automatically reference the thumbnail where available.

## Notes for maintainers

1. If a link 404s, confirm the file exists in the repository and that the path matches the raw link pattern.  
2. To add new files, place them in the appropriate Appendix subfolder, commit, then update the links above.  
3. For archival files you do not want in navigation, place them in `Appendix/_archive` and leave links here so graders can access them by direct URL.
