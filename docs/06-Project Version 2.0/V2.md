## Version 2.0

We could have improved a few things of our project. First of all, we ended up rushing our final prototype. It may have looked somewhat like a tank, but if we had more time, then we could have made it a lot better. We might have 3D printed it instead of trying to build it out of cardboard, or done wood or something more sturdy. The debuggability of our project could have been improved if we had more test pins, and more LED's or buttons. Then we could have made buttons to send specific messages, or shown multiple things with LED's. On top of that, in the code we could have added a way to pause and see what is going on. To make our system more stable, for our motor modules we could have added 12V voltage regulators so that power is not just coming from a raw source. This would have allowed for us to use a battery that we initially intended to have. We would update our protocol design to flow better, it was a little hard to follow, and we really did not need as many bytes as we initially thought. With the updated protocol following the path of each message and what they all are would be easier to do, and make more sense.
