## Version 2.0

We could have improved a few things of our project. First of all, we ended up rushing our final prototype. It may have looked somewhat like a tank, but if we had more time, then we could have made it a lot better. We might have 3D printed it instead of trying to build it out of cardboard, or done wood or something more sturdy. The debuggability of our project could have been improved if we had more test pins, and more LED's or buttons. Then we could have made buttons to send specific messages, or shown multiple things with LED's. On top of that, in the code we could have added a way to pause and see what is going on.
